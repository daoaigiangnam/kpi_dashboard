MSTAR PC AUDIT TOOL - WINDOWS 7 / 10 / 11 (NODE.JS)
===================================================

Mot bo PC_Audit.js dung chung cho Windows 7, Windows 10 va Windows 11.

CAI DAT VA CHAY
1. Giai nen PC_Audit.js, PC_Audit.bat va README vao cung mot thu muc.
2. Chay PC_Audit.bat bang quyen Administrator de thu thap du lieu day du.
3. Neu da co Node.js trong PATH, BAT bo qua cai dat va chay Audit ngay.
4. Neu chua co Node.js: Windows 7 cai Node.js 12.22.12; Windows 10/11 cai Node.js 22.16.0 LTS.
5. Neu Windows 7 khong tai MSI do TLS/chung chi, BAT mo URL MSI chinh thuc de cai thu cong.
6. JSON duoc luu vao thu muc output truoc khi gui len Audit Server.

YEU CAU
- Windows 7 SP1, Windows 10 hoac Windows 11.
- Internet/HTTPS toi may chu Audit.
- Quyen Administrator duoc khuyen nghi de doc WMI/Registry.

LUU Y
Neu Node.js da cai qua PATH nhung qua cu hoac khong tuong thich, BAT van bo qua cai dat theo yeu cau; neu chay loi, hay nang cap Node.js len ban phu hop. Node.js 12 da het ho tro bao mat va chi danh cho Windows 7 legacy.
