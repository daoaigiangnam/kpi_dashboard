# IT Outsourcing Toolkit

Implementation home for the IT Outsourcing tools. The module is designed for authorized customer assets and uses PHP/Laravel native capabilities plus public standards (DNS, RDAP, TLS, HTTP). No commercial API is required for the core checks.

Planned services:
- Domain/RDAP
- DNS
- SSL/TLS
- Website/HTTP
- Email security
- IP/ASN/hosting inference
- Service inventory
- Batch audit/reporting
